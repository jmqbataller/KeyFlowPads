# Contributing to KeyFlow Pads

Help church media teams keep worship audio flowing.

Open an issue describing what happened, your Windows version, the KeyFlow version,
and steps to reproduce the behavior. For audio problems, include the file format,
output device, and whether the issue happened during looping or switching.
Keep personal information and copyrighted recordings out of issue attachments.

For a pull request, explain the operator experience your change improves.
Build the Windows app with the .NET 10 SDK and run the checks relevant to your change.
Audio changes should exercise pad looping, rapid switching, pause, resume, and stop.
Include screenshots for visible interface changes.

Keep the app focused on live playback. Audio reliability, readable controls,
and a small resource footprint guide implementation decisions.
